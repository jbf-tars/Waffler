# Waffler — Windows Requirements
# Install with:  pip install -r requirements_windows.txt
#
# Packages excluded vs macOS version:
#   pyobjc-core / pyobjc-framework-* — macOS-only (Objective-C bridge)
#   rumps                            — macOS menu-bar library
#
# tkinter is NOT listed here because it ships built-in with the
# standard Python Windows installer (python.org).

# ── Audio ──────────────────────────────────────────────────────────────
sounddevice>=0.4.6
numpy>=1.24.0
# FLAC encoding of longer clips before upload (libsndfile ships in the
# wheel's _soundfile_data; PyInstaller's soundfile hook bundles it).
soundfile>=0.12.1
# Meetings: what the computer plays (src/meetings/recorder.py SystemSource),
# through WASAPI loopback of the default output. Without it a meeting on
# Windows records the microphone only (SystemSource.supported() is False).
PyAudioWPatch>=0.2.12

# ── Meetings: two libraries imported inside functions (src/meetings) ──
# Import audio (src/meetings/service.py load_any_audio): soundfile cannot read
# m4a, which is what an iPhone voice memo is, so those go through ffmpeg. The
# wheel carries an ffmpeg program of its own (about 50 MB); without it "Import
# audio" refuses those files unless the person happens to have ffmpeg.
imageio-ffmpeg>=0.6.0
# Meeting notes written by Anthropic's models (src/meetings/llm.py), when the
# person chooses Anthropic. Without it that choice fails at the import.
anthropic>=2.0.0
# keyring is left out on purpose (src/meetings/keys.py): keys reach meetings
# through the environment and nothing calls set_key, so the code path without
# it is the one that ships. `Waffler --self-check` reports it.

# ── Speech to text on this computer (src/local_stt.py) ────────────────
# The engine only: the model is downloaded once, from Settings, into the
# data folder. faster-whisper is CTranslate2: the CPU, or an NVIDIA card
# when its CUDA libraries are already installed. Wheels for everything it
# pulls in exist for Python 3.11 and 3.14 on Windows x64.
faster-whisper>=1.2.0

# ── OpenAI (transcription + styling) ──────────────────────────────────
openai>=1.0.0

# ── Groq (fast transcription + styling) ──────────────────────────────
groq>=0.4.0

# ── Web UI (uses Edge WebView2 on Windows 11, built-in) ───────────────
pywebview>=4.4.0

# ── Clipboard ──────────────────────────────────────────────────────────
pyperclip>=1.8.2

# ── Config / utilities ────────────────────────────────────────────────
pyyaml>=6.0
python-dotenv>=1.0.0
requests>=2.31.0

# ── System Tray (Windows) ──────────────────────────────────────────────
pystray>=0.19.5
Pillow>=10.0.0
